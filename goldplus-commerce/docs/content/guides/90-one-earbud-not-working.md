If only one earbud is working, start with charging. The quiet earbud is very often just flat because it has not been sitting properly in the case. If charging does not fix it, check your phone's sound balance, then reset the pairing between the two earbuds.

# 1. Check the quiet earbud is charging

Each earbud charges through small metal contacts that touch pins inside the case. If one earbud does not sit right, it stays flat while the other charges normally.

- Take both earbuds out and look at the contacts on the earbud and inside the case.
- Clean them gently with a dry cotton bud. Earwax, dust and pocket fluff build up here.
- Put the earbud back and make sure it sits fully down. Many cases show a light when an earbud starts charging.
- Charge for a while, then try again.

# 2. Clean the speaker opening

If the earbud connects but sounds very quiet or muffled, the speaker mesh may be blocked by earwax. Clean it gently with a dry, soft brush. Do not push anything into the mesh and do not run water into it.

# 3. Check the phone's balance and mono settings

A balance slider moved to one side can make an earbud seem dead.

- **Android:** open Settings and search for **balance** or **audio adjustment**. It is usually under Accessibility. Put the left and right balance in the middle.
- **iPhone:** Settings, then Accessibility, then Audio & Visual. Check the **Balance** slider is centred.

While you are there, check **Mono audio**. With mono on, both earbuds play the same sound, which is useful if you only wear one.

# 4. Forget the earbuds and pair again

Many true wireless earbuds work as a pair: one connects to the phone and passes the sound to the other. If that link breaks, one side goes silent.

1. On your phone, open Bluetooth settings and **forget** or **unpair** the earbuds.
2. Put both earbuds back in the case and close the lid for a few seconds.
3. Open the case, take both out together, and pair them again.

Taking them out at the same time helps the two earbuds find each other first.

# 5. Reset the earbuds

If re-pairing does not work, reset the earbuds so they forget all old connections, including the link between left and right. Each model resets differently, usually by holding the touch area or a button for a set time. Follow the manual for your exact model, or message us with the model code and we will tell you how.

After the reset, forget the earbuds on the phone again and pair from scratch.

# 6. Check it is not one device's quirk

Some earbuds can be used one at a time. For example, the listing for our [GP-W06](/products/goldplus-bluetooth-gp-w06) says you can wear one or both. On models like this, a single earbud may connect on its own. Put both in the case and start again if you want stereo.

Also try the earbuds with a different phone. If both sides work there, the issue is a setting on your phone.

# If one earbud still will not work

If you have charged, cleaned, re-paired and reset, and one side still stays silent, the earbud may be faulty.
