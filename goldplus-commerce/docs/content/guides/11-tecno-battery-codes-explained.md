On a Tecno phone, the battery code, a short code that usually starts with BL-, is the surest way to find the right replacement. The phone's name on the box, such as "Spark" or "Camon", is not precise enough, because one name can cover several versions, and similar-looking codes can belong to different batteries. Match the code on the old battery, or use the phone's exact model number, and you avoid most mistakes.

# What a BL- code is

The BL- code identifies the battery itself, not the phone. It is printed on the battery's label, usually in larger type than the rest. Examples from our own shelf include BL-49FT, BL-49ET, BL-20JT, BL-51BX and BL-58BX.

Think of it as the battery's own name. The phone maker decides which battery goes into which phone, and the code is how that battery is tracked.

# Why the code matters more than the phone name

- **One phone name can have several versions.** A phone sold under one name may come in different variants, made at different times or for different markets, and they do not always use the same battery.
- **One battery can fit more than one phone.** The same code is sometimes used across several models. That is why searching by code can turn up phones you did not expect.
- **Similar codes are not interchangeable.** BL-49FT and BL-49ET look almost the same, but they are different batteries. One letter changes the battery.

The code captures all of this in one place. The phone's name does not.

# Do not match by size or mAh

Two batteries can be the same size and have a similar mAh figure and still be wrong for your phone. The connector, the voltage, the position of the contacts and the way the phone reads the battery can all differ. A battery that physically fits but has a different code is not a safe swap.

# Where to find the code

- **Phones with a removable back:** switch off, take off the back cover, and read the label on the battery. Do not take the battery out unless you need to.
- **Phones with a sealed back:** many newer phones are glued shut. Do not prise them open yourself. Use the model number instead.
- **The old battery itself:** if you already have it out, the code is on the label.

# Where to find the model number

Open Settings, then About phone. You will see the model name and a model number, a short code made of letters and numbers. Write it down exactly. If the phone will not switch on, look on the box, your receipt, or a sticker under the battery cover.

# Before you fit it

- **Never use or charge a swollen battery.** If the old one is puffy, set it aside safely.
- **Compare the codes** on the old and new battery before you fit it.
- **Let the phone learn the new battery.** For the first few days, the percentage may be a little off while the phone adjusts.
