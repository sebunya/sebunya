For most people, **exFAT** is the best all-round choice: it works on modern Windows and Mac computers and many newer devices, and it can hold files larger than 4GB. Use **FAT32** for older TVs, car stereos and devices that will not read anything else. Use **NTFS** only for a drive that stays with Windows computers.

> Formatting erases everything on the drive. Copy off anything you need first.

# FAT32

The oldest and most widely supported of the three.

- **Works almost everywhere:** Windows, Mac, Linux, many TVs, car stereos, game consoles, cameras and older devices.
- **Single-file limit of 4GB.** A file bigger than that, such as a long HD film or a large backup file, will not copy. You will see an error saying the file is too large.
- **Windows' built-in format window only offers FAT32 for drives up to 32GB.** Larger drives can still use FAT32, but need other tools.

**Pick FAT32 for:** music for the car, older TVs, and devices whose manual asks for it.

# exFAT

Designed for flash drives and memory cards.

- **No practical file-size limit** for everyday use, so big films and backups copy fine.
- **Works on** current Windows and Mac computers, and many newer TVs, phones and cameras.
- **Some older devices cannot read it,** especially older car stereos and TVs.

**Pick exFAT for:** moving files between Windows and Mac, large films, phone backups, and most drives over 32GB.

# NTFS

Windows' own format for internal drives.

- **Handles very large files** and has features Windows uses, such as file permissions.
- **Macs can read NTFS but cannot write to it** without extra software.
- **Many TVs, car stereos and phones** do not support it, or only read it.

**Pick NTFS for:** a drive used only with Windows computers, for example an office backup drive.

# Which one for your device?

- **Car stereo:** FAT32, unless the stereo's manual says otherwise.
- **TV:** check the manual. FAT32 is the safe choice; many newer TVs also read exFAT and some read NTFS.
- **Windows and Mac:** exFAT.
- **Android phone over OTG:** FAT32 or exFAT usually work; NTFS often does not.
- **Windows only:** NTFS or exFAT.

# How to format on Windows

1. Plug in the drive and open File Explorer.
2. Right-click the drive and choose **Format**.
3. Under **File system**, choose FAT32, exFAT or NTFS.
4. Leave **Allocation unit size** at the default.
5. Give it a name under **Volume label** if you like.
6. Tick **Quick Format** and click **Start**.

# How to format on a Mac

1. Plug in the drive and open **Disk Utility**.
2. Select the drive in the list on the left.
3. Click **Erase**.
4. Choose **ExFAT**, or **MS-DOS (FAT)** for FAT32.
5. Click **Erase**.

# Tips

- **Check the device manual first.** It often says exactly which format it needs.
- **Format in the device itself** where it offers the option, such as some TVs and cameras.
- **Eject before unplugging,** every time.
- If the drive is not seen at all after formatting, try a different USB port or computer before assuming it has failed.
