To check a GoldPlus product is genuine, find the code on the security hologram on its packaging and enter it on our [verification page](/verification). A genuine code is confirmed. If the code is rejected, has already been used, or the package looks tampered with, report it on our [fake product page](/support/fake) and we will investigate.

# Why it is worth checking

Every genuine GoldPlus product has a code. A copy can look the same on the outside, so the packaging alone is not proof.

Checking the code takes a minute and confirms the product in your hand is the real thing before you rely on it. That matters most for things you trust every day, like a charger or a power bank.

# Step 1: find the code

Look on the product packaging for the **security hologram**. The verification code is on it.

Have the packaging in front of you and good light, so you can read every character correctly.

# Step 2: enter it on the verification page

1. Open the [verification page](/verification).
2. Type the code into the **Verification code** box exactly as printed.
3. Tap **Verify code**.

The page tells you whether the code is genuine.

# Each code works once

Codes can only be verified once. So it helps to know what an "already used" result is telling you. If a code has already been verified, it usually means the package was opened before you bought it. If you bought it as new and sealed, that is a reason to ask questions.

# If the code does not work

If your code is rejected, it has already been used, or the package looks tampered with, report it. We investigate every submission.

Before you do, check you typed the code correctly, character by character. Then, if it still fails, go to the report page.

# How to report a fake

Use the [report a counterfeit product](/support/fake) form. It asks for:

- **Where you saw or bought it.** Name the shop or seller and the area, and add any details that help us identify the location. You can pick your district from the list.
- **What the product looked like.** Describe it as well as you can.
- **The hologram code, if there is one.** This is optional, but it tells us which batch the counterfeit is targeting.
- **Your phone number,** so we can contact you to verify details. An email address is optional.

We investigate every submission and refer serious cases to the relevant authorities. Your report helps protect other buyers.

# Your privacy

When you check a code or report a fake, we record where fakes turn up, never who you are. Your details are not shared.

# Good habits when buying

- Check the code as soon as you can, ideally before you rely on the product.
- Be careful of packaging that has clearly been opened, resealed or has a damaged hologram.
- Keep your receipt or order confirmation.
- If something feels wrong, report it rather than ignoring it. One report can help stop a batch of fakes.
