| F7-01 | 3A | Distributed abuse control is proven only for the login/auth family. The prior `global` limiter keyed on `c.req.path`, so a caller got the full budget for every distinct URL it invented — unbounded by construction. | High | **CLOSED** | One authoritative layer `middleware/publicAbuseControl.ts` + pure `domain/security/PublicEndpointPolicy.ts`: `classifyPublicEndpoint` maps every request to one of a closed family set (path params/case/query/slashes collapse), the Redis counter is keyed on the FAMILY not the path, `global` is one shared budget per client, and each family declares a Redis-outage policy (human forms STRICT ÷4 local; HMAC provider webhooks GENEROUS full-local so a blip can't drop a payment confirmation). Proof: `tests/unit/PublicEndpointPolicy.test.ts` 11/11 (path variation → one family; 500 invented URLs → one `global` key); `tests/integration/PublicAbuseControl.integration.test.ts` 5/5 on real Redis (path variation shares one budget, two replicas share one budget, families isolated, no path/PII in keys) + existing RedisAbuseControl 11/11.
